NORMALIZATION RULES:
To improve matching:
- Ignore case
- Ignore accents when matching
- Trim extra spaces
- Treat commas, “&”, “FEAT.”, “FEAT”, “WITH”, “X”, and “/” as separators
- Be careful with short names to avoid false matches
- Do not match partial names too loosely

Examples:
- “CARÍN LEÓN” should match “CARIN LEON”
- “ÁNGELA AGUILAR” should match “ANGELA AGUILAR”
- “BANDA MS DE SERGIO LIZÁRRAGA” should match Banda MS
- “LUIS ANGEL ‘EL FLACO’” should match Luis Ángel El Flaco if that artist exists in our database

FALSE MATCH PREVENTION:
Do not match tiny fragments or generic names accidentally.

Example:
- “CD9” should only match CD9
- “DLD” should only match DLD
- “Reik” should only match Reik
- “Camila” should match the Mexican group Camila, but be careful not to confuse with Camilo
- “Peso Pluma” should not match unrelated text unless the full phrase appears
- “Junior H” should match Junior H only
