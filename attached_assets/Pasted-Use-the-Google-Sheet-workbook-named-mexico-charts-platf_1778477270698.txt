8. Matching Normalization

To improve matching:
- ignore case
- ignore accents
- trim spaces
- normalize punctuation
- treat commas, &, “feat.”, “featuring”, “with”, “x”, “/”, and “and” as artist separators
- match full artist names, not tiny fragments
- avoid false matches with short names

Examples:
- CARÍN LEÓN should match CARIN LEON
- ÁNGELA AGUILAR should match ANGELA AGUILAR
- PESO PLUMA should match Peso Pluma
- CAMILA should not accidentally match Camilo
- REIK should only match Reik
- CD9 should only match CD9

9. Ranking Accuracy

Always preserve the original platform rank.

Do not re-rank filtered Mexican-only views.

#3 BTS

#4 Peso Pluma

#1 Fuerza Regida
